# Глоссарий шахматных терминов

> **Для AI-агента:** При переводе текста строго следуй этому словарю. Если термин присутствует в таблице, используй указанный перевод. Не переводи термины дословно.

---

## Термины и перевод

| Оригинал (EN) | Перевод (RU) | Примечание |
|---------------|--------------|------------|
| Rossolimo | Россолимо | Вариант сицилианской защиты |
| Maroczy Bind | Система Мароци | Структура с пешками на c4 и e4 |
| Samisch | Земиш | Фамилия шахматиста (Friedrich Samisch) |
| Nimzo-Indian Defence | Защита Нимцовича | Дебют 1.d4 Nf6 2.c4 e6 3.Nc3 Bb4 |
| Queen's Gambit | Ферзевый гамбит | Дебют 1.d4 d5 2.c4 |
| King's Indian Defence | Староиндийская защита | Дебют 1.d4 Nf6 2.c4 g6 |
| English Opening | Английское начало | Дебют 1.c4 |
| Pawn Island | Пешечный островок | Именно островОК, а не остров |
| White | белый | Никогда не переводи как "светлый" |
| Black | чёрный | Относится к фигурам и полям |
| Isolated Pawn | Изолированная пешка | Пешка без своих пешек на соседних вертикалях |
| Doubled Pawns | Сдвоенные пешки | Две пешки одного цвета на одной вертикали |
| Backward Pawn | Отсталая пешка | Пешка, отстающая в развитии |
| Passed Pawn | Проходная пешка | Пешка без препятствий на пути к превращению |
| Fianchetto | Фианкетто | Развитие слона на g2/b2 или g7/b7 |
| Zugzwang | Цугцванг | Положение, когда любой ход ухудшает позицию |
| Tempo | Темп | Ход, время |
| Initiative | Инициатива | Активность, давление |
| Compensation | Компенсация | Возмещение за материал или позицию |
| Endgame | Эндшпиль | Заключительная стадия партии |
| Middlegame | Миттельшпиль | Середина партии |
| Opening | Дебют | Начальная стадия партии |
