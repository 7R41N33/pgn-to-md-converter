## Why

The chess diagrams generated by `fen_builder` currently display only the board with coordinates. Educational chess materials (puzzles, quizzes, training exercises) require a text caption below the diagram — a question, instruction, or commentary that provides context. Without this, users must manually composite images or add text separately, which is inconvenient for automated workflows like `--inline-images` in `build_markdown`.

## What Changes

- Add an optional `caption` parameter to the fen_builder CLI (`--caption` flag)
- Add a corresponding `caption` parameter to `GenerateBoard`, `GenerateDiagram`, `GenerateDiagramBase64`, and `GenerateDiagramToWriter` in the `fenlib` package
- Render the caption as center-aligned, word-wrapped text below the board area
- If the text exceeds the diagram width, split it across multiple lines
- Keep backward compatibility: existing callers that don't pass a caption get the same output as before

## Capabilities

### New Capabilities
- `diagram-caption`: Render center-aligned word-wrapped caption text below the chess board image
